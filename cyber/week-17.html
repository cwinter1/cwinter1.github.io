Concept 1 — Why Memory?

Disk forensics finds what was stored. Memory forensics finds what was running — including fileless malware, injected code, and secrets that never touched disk. RAM is the most volatile artifact (powered off = gone), which is why evidence collection orders RAM capture first.

A process in memory has: a virtual address space, a PEB (Process Environment Block) describing it, thread stacks, mapped DLLs, and handles. Malware that injects into a legitimate process (process hollowing, DLL injection) lives only in these structures — no file on disk to scan.

Analogy to data engineering: A running Spark job has in-memory state (shuffle buffers, accumulators, broadcast variables) that disappears the instant the job ends. Memory forensics is like attaching a debugger to that job before it terminates to extract the live state.

        "-f", image_path,
        "--renderer", "json",

        cmd.extend(extra_args)

    start = time.monotonic()

        result = subprocess.run(cmd, capture_output=True, text=True, timeout=300)
        duration = time.monotonic() - start

        return VolatilityResult(plugin, image_path, rows, duration_seconds=duration)
    except subprocess.TimeoutExpired:
        return VolatilityResult(plugin, image_path, [], error="timeout after 300s")
    except json.JSONDecodeError as exc:
        return VolatilityResult(plugin, image_path, [], error=f"JSON parse error: {exc}")

Concept 2 — Volatility Core Plugins


Volatility 3 ships with plugins for every major memory structure. The four most important for detection:


    

  • windows.pslist — process list from the EPROCESS doubly-linked list
    • 

  • windows.pstree — same data formatted as a tree
    • 

  • windows.cmdline — command-line arguments for each process (read from PEB)
    • 

  • windows.dlllist — all loaded DLLs for a process (mapped in virtual address space)
    • 

  • windows.malfind — scans for VAD regions with PAGE_EXECUTE_READWRITE that don't map to a file on disk (classic injection indicator)
    • 

  • windows.netscan — active and recently closed network connections (from TcpE/UdpA structures)
    • 



Analogy: pslist is a SELECT * FROM processes — straightforward read of a known structure. malfind is more like SELECT * FROM memory_pages WHERE permissions='rwx' AND backing_file IS NULL — it scans a large structure looking for anomalies.

@dataclass
class ProcessInfo:
    pid: int
    ppid: int
    name: str
    create_time: str
    cmdline: Optional[str] = None
    dlls: list[str] = None
    network_connections: list[dict] = None
    malfind_hits: list[dict] = None

    def __post_init__(self):
        if self.dlls is None:
            self.dlls = []
        if self.network_connections is None:
            self.network_connections = []
        if self.malfind_hits is None:
            self.malfind_hits = []

    def has_suspicious_cmdline(self) -> bool:
        if not self.cmdline:
            return False
        indicators = [
            r"-[Ee][Nn][Cc]",          # encoded command
            r"-[Ww]indowstyle\s+[Hh]idden",
            r"bypass",
            r"IEX\s*\(",
            r"downloadstring",
            r"invoke-expression",
        ]
        cl = self.cmdline.lower()
        return any(re.search(pat, self.cmdline, re.IGNORECASE) for pat in indicators)

    def has_unsigned_dll(self, signed_prefixes: list[str] | None = None) -> bool:
        if signed_prefixes is None:
            signed_prefixes = [
                r"c:\windows\system32\\",
                r"c:\windows\syswow64\\",
                r"c:\program files\\",
            ]
        for dll in self.dlls:
            dll_lower = dll.lower()
            if not any(dll_lower.startswith(p) for p in signed_prefixes):
                return True
        return False

Concept 3 — Process Hollowing Detection


Process hollowing: attacker creates a legitimate process in SUSPENDED state, unmaps its memory, writes malicious code, then resumes. The process table shows svchost.exe but its memory contains shellcode.


Detection signatures:


    

  1. Process has no mapped image in VAD (virtual address descriptor tree) — the executable section has no backing file
    2. 

  2. malfind finds a PAGE_EXECUTE_READWRITE VAD that starts with MZ header (PE file)
    3. 

  3. Process path in memory does not match disk path (image path spoofing)
    4. 

  4. Thread start address points outside any loaded module
    5. 



Example:


from dataclasses import dataclass
from enum import Enum

class HollowingIndicator(Enum):
    NO_DISK_BACKING    = "executable_vad_has_no_disk_file"
    RWX_WITH_MZ        = "rwx_region_starts_with_mz_header"
    PATH_MISMATCH      = "image_path_does_not_match_disk"
    ORPHAN_THREAD      = "thread_start_outside_loaded_modules"

@dataclass
class MalfindHit:
    pid: int
    process_name: str
    vad_start: int     # hex address
    vad_end: int
    protection: str    # e.g. "PAGE_EXECUTE_READWRITE"
    file_output: str   # first bytes — MZ header = PE, 0x90 = nop sled
    disk_path: Optional[str] = None  # None means no backing file

@dataclass
class HollowingFinding:
    pid: int
    process_name: str
    indicators: list[HollowingIndicator]
    confidence: str    # "HIGH" / "MEDIUM" / "LOW"
    details: str

def assess_hollowing(hit: MalfindHit, pslist_entry: dict) -> HollowingFinding:
    indicators = []

    if hit.disk_path is None:
        indicators.append(HollowingIndicator.NO_DISK_BACKING)

    if hit.file_output.startswith("4d5a") or hit.file_output.lower().startswith("mz"):
        indicators.append(HollowingIndicator.RWX_WITH_MZ)

    if hit.protection == "PAGE_EXECUTE_READWRITE":
        pass  # already captured by malfind selection

    confidence = "LOW"
    if len(indicators) >= 2:
        confidence = "HIGH"
    elif len(indicators) == 1:
        confidence = "MEDIUM"

    details = f"VAD {hex(hit.vad_start)}-{hex(hit.vad_end)}, protection={hit.protection}"
    return HollowingFinding(hit.pid, hit.process_name, indicators, confidence, details)

def parse_prefetch_filename(pf_name: str) -> tuple[str, str]:
    """Extract (executable_name, hash) from PF filename."""
    base = pf_name.replace(".pf", "").replace(".PF", "")
    parts = base.rsplit("-", 1)
    if len(parts) == 2:
        return parts[0], parts[1]
    return base, ""

def correlate_prefetch_with_timeline(
    prefetch_entries: list[PrefetchEntry],
    timeline_start: datetime,
    timeline_end: datetime,
) -> list[PrefetchEntry]:
    """Return prefetch entries with execution times overlapping the incident window."""
    results = []
    for entry in prefetch_entries:
        for run_time in entry.last_run_times:
            if timeline_start <= run_time <= timeline_end:
                results.append(entry)
                break
    return results

Concept 2 — Timeline Analysis and Super-timeline


A super-timeline merges timestamps from all artifact sources into one chronological view. The MACB notation describes which timestamp type fired: M=modified, A=accessed, C=changed ($MFT metadata), B=birth (created).


Tool: log2timeline.py / Plaso generates Plaso storage files → psort.py exports to CSV/JSON/Excel.


Manual approach in Python: normalize each artifact's timestamps to a common schema and sort.


Example:


from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Optional
import json

class ArtifactSource(Enum):
    PREFETCH     = "prefetch"
    EVENT_LOG    = "event_log"
    SYSMON       = "sysmon"
    MFT          = "mft"
    USN_JOURNAL  = "usn_journal"
    LNK_FILE     = "lnk_file"
    SHIMCACHE    = "shimcache"
    NETWORK_LOG  = "network_log"
    REGISTRY     = "registry"

@dataclass
class SuperTimelineEntry:
    timestamp: datetime
    source: ArtifactSource
    macb: str              # e.g. "M..B", "...B", "MACB"
    hostname: str
    short_description: str
    long_description: str
    artifact_path: str
    technique_id: Optional[str] = None
    confidence: str = "MEDIUM"

    def to_csv_row(self) -> str:
        return ",".join([
            self.timestamp.isoformat(),
            self.source.value,
            self.macb,
            self.hostname,
            f'"{self.short_description}"',
            f'"{self.long_description}"',
        ])

@dataclass
class SuperTimeline:
    case_name: str
    hostname: str
    entries: list[SuperTimelineEntry] = field(default_factory=list)

    def add(self, entry: SuperTimelineEntry) -> None:
        self.entries.append(entry)
        self.entries.sort(key=lambda e: e.timestamp)

    def filter_by_technique(self, technique_id: str) -> list[SuperTimelineEntry]:
        return [e for e in self.entries if e.technique_id == technique_id]

    def pivot_by_hour(self) -> dict[str, int]:
        counts: dict[str, int] = {}
        for e in self.entries:
            hour_key = e.timestamp.strftime("%Y-%m-%d %H:00")
            counts[hour_key] = counts.get(hour_key, 0) + 1
        return dict(sorted(counts.items()))

    def export_json(self) -> str:
        return json.dumps({
            "case": self.case_name,
            "hostname": self.hostname,
            "entry_count": len(self.entries),
            "entries": [
                {
                    "timestamp": e.timestamp.isoformat(),
                    "source": e.source.value,
                    "macb": e.macb,
                    "short": e.short_description,
                    "technique": e.technique_id,
                }
                for e in self.entries
            ],
        }, indent=2)

    """Parse a single EVTX event serialized as XML (as returned by python-evtx)."""
    try:
        ns = {"e": "http://schemas.microsoft.com/win/2004/08/events/event"}
        root = ET.fromstring(xml_string)
        system = root.find("e:System", ns)
        if system is None:
            return None

        event_id = int(system.findtext("e:EventID", "0", ns))
        time_created = system.find("e:TimeCreated", ns)
        timestamp_str = time_created.attrib.get("SystemTime", "") if time_created is not None else ""
        timestamp = datetime.fromisoformat(timestamp_str.replace("Z", "+00:00")) if timestamp_str else datetime.min
        computer = system.findtext("e:Computer", "", ns)
        channel = system.findtext("e:Channel", "", ns)
        provider_el = system.find("e:Provider", ns)
        provider = provider_el.attrib.get("Name", "") if provider_el is not None else ""

        event_data = root.find("e:EventData", ns)
        data: dict[str, str] = {}
        if event_data is not None:
            for data_el in event_data.findall("e:Data", ns):
                name = data_el.attrib.get("Name", "")
                value = data_el.text or ""
                if name:
                    data[name] = value

        return ParsedEvent(event_id, timestamp, computer, channel, provider, data)
    except Exception:
        return None

def extract_security_events(events: list[ParsedEvent], event_ids: list[int]) -> list[ParsedEvent]:
    return [e for e in events if e.event_id in event_ids]

def find_logon_logoff_pairs(events: list[ParsedEvent]) -> list[dict]:
    """Match 4624 logon events with 4634/4647 logoff events by LogonId."""
    logons: dict[str, ParsedEvent] = {}
    sessions = []

    for event in sorted(events, key=lambda e: e.timestamp):
        if event.event_id == 4624:
            logon_id = event.data.get("TargetLogonId", "")
            if logon_id:
                logons[logon_id] = event
        elif event.event_id in (4634, 4647):
            logon_id = event.data.get("TargetLogonId", "")
            if logon_id in logons:

                duration_s = (event.timestamp - logon_event.timestamp).total_seconds()
                sessions.append({
                    "logon_id": logon_id,
                    "user": logon_event.data.get("TargetUserName", ""),
                    "logon_type": logon_event.data.get("LogonType", ""),
                    "logon_time": logon_event.timestamp.isoformat(),
                    "logoff_time": event.timestamp.isoformat(),
                    "duration_seconds": duration_s,
                    "source_ip": logon_event.data.get("IpAddress", ""),
                })
    return sessions

Concept 1 — The Correlation Problem


Memory forensics and Sysmon/EDR telemetry capture the same attacker activity from different angles. Memory sees the current state; Sysmon logs the events as they happened. Cross-correlating them:


    

  1. A process in memory (PSList) should have a matching Sysmon EID 1 (process create) with the same PID
    2. 

  2. DLLs loaded in memory (DLLList) should have matching Sysmon EID 7 (image loaded) entries
    3. 

  3. Network connections in memory (NetScan) should have matching Sysmon EID 3 (network connect)
    4. 

  4. Malfind hits indicate code injection — look back in Sysmon for EID 8 (CreateRemoteThread)
    5. 



Gaps — a process in memory with no Sysmon EID 1 — indicate either: Sysmon wasn't running when it started, or the process was created via a technique Sysmon doesn't capture (kernel exploit).

    pid: int
    process_name: str
    memory_entry: Optional[dict]
    sysmon_create: Optional[SysmonEvent]
    status: CorrelationStatus
    anomalies: list[str] = field(default_factory=list)

    def severity(self) -> str:
        if self.status == CorrelationStatus.MEMORY_ONLY:
            return "HIGH"
        if self.status == CorrelationStatus.CONFLICT:
            return "HIGH"
        if self.anomalies:
            return "MEDIUM"
        return "LOW"

def correlate_pslist_with_sysmon(
    pslist: list[dict],
    sysmon_events: list[SysmonEvent],
    event_id_filter: int = 1,
) -> list[ProcessCorrelation]:
    sysmon_by_pid: dict[int, SysmonEvent] = {
        e.pid: e for e in sysmon_events if e.event_id == event_id_filter
    }
    correlations = []
    for proc in pslist:
        pid = proc["PID"]
        name = proc["ImageFileName"]
        sysmon_event = sysmon_by_pid.get(pid)

        if sysmon_event is None:
            status = CorrelationStatus.MEMORY_ONLY
            anomalies = ["No Sysmon EID 1 for this PID"]
        elif sysmon_event.process_name.lower() != name.lower():
            status = CorrelationStatus.CONFLICT
            anomalies = [f"Name mismatch: memory={name}, sysmon={sysmon_event.process_name}"]
        else:
            status = CorrelationStatus.MATCHED
            anomalies = []

        correlations.append(ProcessCorrelation(pid, name, proc, sysmon_event, status, anomalies))

    seen_pids = {p["PID"] for p in pslist}
    for ev in sysmon_events:
        if ev.event_id == event_id_filter and ev.pid not in seen_pids:
            correlations.append(ProcessCorrelation(
                ev.pid, ev.process_name, None, ev,
                CorrelationStatus.SYSMON_ONLY,
                ["Process no longer in memory — may have exited"],
            ))
    return correlations

Concept 2 — Detecting Process Hollowing via Correlation


The definitive hollow process signature requires ALL of:


    

  1. Process in PSList with a name that matches a legitimate binary
    2. 

  2. Malfind shows PAGE_EXECUTE_READWRITE VAD with no disk backing (or MZ header)
    3. 

  3. Sysmon EID 1 CreateTime and process name match memory — but EID 8 (CreateRemoteThread) or EID 10 (ProcessAccess) occurred before the process was "fully started"
    4. 

  4. DLLList shows a DLL loaded from a temp path or user profile
    5.

@dataclass
class HollowProcessHunt:
    pid: int
    process_name: str
    pslist_match: bool
    malfind_hit: Optional[MalfindHit]
    sysmon_create: Optional[SysmonEvent]
    sysmon_remote_thread: Optional[SysmonEvent]   # EID 8
    suspicious_dlls: list[str]
    verdict: str = ""
    confidence: str = ""

    def assess(self) -> "HollowProcessHunt":
        score = 0
        reasons = []

        if self.malfind_hit and self.malfind_hit.disk_path is None:
            score += 3
            reasons.append("RWX VAD no disk backing")

        if self.malfind_hit and self.malfind_hit.file_output.startswith("4d5a"):
            score += 2
            reasons.append("MZ header in injected region")

        if self.sysmon_remote_thread:
            score += 3
            reasons.append("CreateRemoteThread EID 8 observed")

        if self.suspicious_dlls:
            score += 1
            reasons.append(f"{len(self.suspicious_dlls)} suspicious DLLs")

        if score >= 6:
            self.confidence = "HIGH"
            self.verdict = "HOLLOW_PROCESS: " + "; ".join(reasons)
        elif score >= 3:
            self.confidence = "MEDIUM"
            self.verdict = "SUSPICIOUS: " + "; ".join(reasons)
        else:
            self.confidence = "LOW"
            self.verdict = "BENIGN"

        return self

def hunt_hollow_processes(
    pslist: list[dict],
    malfind_results: list[MalfindHit],
    sysmon_events: list[SysmonEvent],
    dll_map: dict[int, list[str]],
) -> list[HollowProcessHunt]:
    malfind_by_pid = {m.pid: m for m in malfind_results}
    sysmon_create  = {e.pid: e for e in sysmon_events if e.event_id == 1}
    sysmon_rthread = {e.pid: e for e in sysmon_events if e.event_id == 8}

    suspicious_prefixes = (
        r"c:\users",
        r"c:\programdata",
        r"c:\windows\temp",
        r"c:\temp",
    )

    results = []
    for proc in pslist:
        pid = proc["PID"]
        dlls = dll_map.get(pid, [])
        susp_dlls = [d for d in dlls if d.lower().startswith(suspicious_prefixes)]
        hunt = HollowProcessHunt(
            pid=pid,
            process_name=proc["ImageFileName"],
            pslist_match=True,
            malfind_hit=malfind_by_pid.get(pid),
            sysmon_create=sysmon_create.get(pid),
            sysmon_remote_thread=sysmon_rthread.get(pid),
            suspicious_dlls=susp_dlls,
        )
        results.append(hunt.assess())

    return [r for r in results if r.confidence in ("HIGH", "MEDIUM")]

Concept 1 — PCAP Analysis for Forensics


A packet capture is ground truth for network activity. Where logs may be incomplete, altered, or absent, a PCAP records every byte. For forensic purposes:


    

  • Full packet capture (FPC): captures headers + payload — richest evidence, large storage
    • 

  • NetFlow/IPFIX: metadata only (src/dst IP, port, bytes, duration) — smaller, no payload
    • 

  • Zeek logs: protocol-parsed metadata in structured logs — middle ground
    • 



The forensic workflow:


    

  1. Extract all unique connections (5-tuple: src_ip, src_port, dst_ip, dst_port, proto)
    2. 

  2. Identify HTTP/HTTPS flows and extract hostnames (from TLS SNI)
    3. 

  3. Flag connections to known-bad IPs/domains (IOC matching)
    4. 

  4. Identify data exfiltration patterns (large outbound transfers, unusual ports)
    5. 

  5. Reconstruct TCP streams for interesting flows
    6. 



Example:

    src_port: int

    dst_port: int

            return False

        if self.bytes_received == 0:
            return float("inf")
        return self.bytes_sent / self.bytes_received

Concept 2 — DNS Forensics


DNS is the most reliable network forensic artifact. Every C2 channel that uses domain names must query DNS. Key patterns:


    

  • High-entropy domains: DGA (domain generation algorithm) domains look random — xkqjfbz.com
    • 

  • DNS tunneling: encoded data in subdomain labels — queries are very long, high TXT record usage
    • 

  • Fast flux: same domain resolves to many different IPs rapidly
    • 

  • Beaconing via DNS: regular-interval queries to the same domain, even if HTTP is blocked
    •

import math
import re
from dataclasses import dataclass
from collections import Counter
from datetime import datetime

@dataclass
class DNSQuery:
    timestamp: datetime
    client_ip: str
    query_name: str
    query_type: str   # "A", "AAAA", "TXT", "MX", "CNAME"
    response_code: str  # "NOERROR", "NXDOMAIN", "SERVFAIL"
    response_ips: list[str]
    ttl: Optional[int] = None

def shannon_entropy(string: str) -> float:
    if not string:
        return 0.0
    freq = Counter(string.lower())
    total = len(string)
    return -sum((c / total) * math.log2(c / total) for c in freq.values())

def classify_dga(domain: str, entropy_threshold: float = 3.5, min_length: int = 12) -> tuple[bool, str]:
    """Return (is_dga, reason)."""
    labels = domain.split(".")
    hostname = labels[0] if labels else domain
    tld = "." + ".".join(labels[-2:]) if len(labels) >= 2 else ""

    if len(hostname) < min_length:
        return False, "too short for DGA"

    entropy = shannon_entropy(hostname)
    digit_ratio = sum(c.isdigit() for c in hostname) / len(hostname)
    vowel_ratio = sum(c in "aeiou" for c in hostname.lower()) / len(hostname)

    reasons = []
    if entropy >= entropy_threshold:
        reasons.append(f"high entropy={entropy:.2f}")
    if digit_ratio > 0.3:
        reasons.append(f"high digit ratio={digit_ratio:.2f}")
    if vowel_ratio < 0.1:
        reasons.append(f"low vowel ratio={vowel_ratio:.2f}")

    is_dga = len(reasons) >= 2
    return is_dga, "; ".join(reasons) if reasons else "normal"

def detect_dns_tunneling(queries: list[DNSQuery], min_label_length: int = 40) -> list[DNSQuery]:
    """Flag queries with very long subdomain labels (common in DNS tunneling)."""
    suspicious = []
    for q in queries:
        labels = q.query_name.split(".")
        if labels and len(labels[0]) >= min_label_length:
            suspicious.append(q)
        if q.query_type == "TXT" and q.response_code == "NOERROR":
            suspicious.append(q)
    return suspicious

Concept 3 — Evidence Packaging and Chain of Custody


Digital evidence must be collected, hashed, and documented in a chain of custody to be admissible. The chain of custody answers: who collected it, when, how, and who has handled it since.


Example:


from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
import hashlib
import json

@dataclass
class CustodyTransfer:
    timestamp: datetime
    from_person: str
    to_person: str
    method: str           # "hand delivery" / "encrypted email" / "secure upload"
    notes: str

@dataclass
class EvidencePackage:
    evidence_id: str
    description: str
    collected_by: str
    collected_at: datetime
    collection_method: str
    original_location: str
    sha256: str
    md5: str
    size_bytes: int
    storage_location: str
    custody_chain: list[CustodyTransfer] = field(default_factory=list)
    notes: list[str] = field(default_factory=list)

    def add_transfer(self, transfer: CustodyTransfer) -> None:
        self.custody_chain.append(transfer)

    def current_custodian(self) -> str:
        if not self.custody_chain:
            return self.collected_by
        return self.custody_chain[-1].to_person

    def to_report(self) -> str:
        lines = [
            f"Evidence ID   : {self.evidence_id}",
            f"Description   : {self.description}",
            f"Collected by  : {self.collected_by} at {self.collected_at.isoformat()}",
            f"Method        : {self.collection_method}",
            f"Original path : {self.original_location}",
            f"SHA-256       : {self.sha256}",
            f"MD5           : {self.md5}",
            f"Size          : {self.size_bytes:,} bytes",
            f"Storage       : {self.storage_location}",
            f"Custodian     : {self.current_custodian()}",
            "",
            "Chain of custody:",
        ]
        for i, t in enumerate(self.custody_chain, 1):
            lines.append(f"  {i}. {t.timestamp.isoformat()} — {t.from_person} → {t.to_person} ({t.method})")
        return "\n".join(lines)

def hash_file_content(content: bytes) -> tuple[str, str]:
    return (

Concept 1 — Automating the Forensics Pipeline


A forensics pipeline runs the same steps every time: acquire, hash, parse, correlate, output a findings report. Automating it with Python ensures repeatability, eliminates manual errors, and creates an audit trail.


Example:


from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional, Callable
import time
import json

@dataclass
class ForensicStepResult:
    step_name: str
    success: bool
    output: dict
    error: Optional[str]
    duration_seconds: float

ForensicStep = Callable[[dict], ForensicStepResult]

@dataclass
class ForensicsRun:
    case_id: str
    hostname: str
    started_at: datetime
    completed_at: Optional[datetime] = None
    steps: list[ForensicStepResult] = field(default_factory=list)
    hollow_findings: list[HollowProcessHunt] = field(default_factory=list)
    super_timeline: Optional[SuperTimeline] = None
    suspicious_flows: list[tuple[NetworkFlow, list[str]]] = field(default_factory=list)
    evidence_packages: list[EvidencePackage] = field(default_factory=list)

    def add_step(self, result: ForensicStepResult) -> None:
        self.steps.append(result)

    def success_rate(self) -> float:
        if not self.steps:
            return 0.0
        return sum(1 for s in self.steps if s.success) / len(self.steps)

    def to_report_json(self) -> str:
        return json.dumps({
            "case_id": self.case_id,
            "hostname": self.hostname,
            "started_at": self.started_at.isoformat(),
            "completed_at": self.completed_at.isoformat() if self.completed_at else None,
            "steps_total": len(self.steps),
            "steps_success": sum(1 for s in self.steps if s.success),
            "hollow_findings": len(self.hollow_findings),
            "suspicious_flows": len(self.suspicious_flows),
            "evidence_items": len(self.evidence_packages),
        }, indent=2)

def run_forensics_pipeline(
    case_id: str,
    hostname: str,
    pslist: list[dict],
    malfind_results: list[MalfindHit],
    sysmon_events: list[SysmonEvent],
    dll_map: dict[int, list[str]],
    network_flows: list[NetworkFlow],
    dns_queries: list[DNSQuery],
    ioc_ips: set[str],
    ioc_domains: set[str],
    output_path: Optional[str] = None,
) -> ForensicsRun:
    run = ForensicsRun(case_id=case_id, hostname=hostname, started_at=datetime.utcnow())

    # Step 1: hollow process hunt
    t0 = time.monotonic()
    try:
        hollow = hunt_hollow_processes(pslist, malfind_results, sysmon_events, dll_map)
        run.hollow_findings = hollow
        run.add_step(ForensicStepResult("hollow_hunt", True, {"findings": len(hollow)}, None, time.monotonic()-t0))
    except Exception as exc:
        run.add_step(ForensicStepResult("hollow_hunt", False, {}, str(exc), time.monotonic()-t0))

    # Step 2: build super-timeline
    t0 = time.monotonic()
    try:
        tl = SuperTimeline(case_id, hostname)
        for ev in sysmon_events:
            tl.add(SuperTimelineEntry(
                timestamp=ev.timestamp,
                source=ArtifactSource.SYSMON,
                macb="....",
                hostname=hostname,
                short_description=f"Sysmon EID {ev.event_id}: {ev.process_name}",
                long_description=str(ev.data),
                artifact_path="Sysmon.evtx",
            ))
        run.super_timeline = tl
        run.add_step(ForensicStepResult("super_timeline", True, {"entries": len(tl.entries)}, None, time.monotonic()-t0))
    except Exception as exc:
        run.add_step(ForensicStepResult("super_timeline", False, {}, str(exc), time.monotonic()-t0))

    # Step 3: network flag
    t0 = time.monotonic()
    try:
        flagged = flag_suspicious_flows(network_flows, ioc_ips, ioc_domains)
        run.suspicious_flows = flagged
        run.add_step(ForensicStepResult("network_flag", True, {"flagged": len(flagged)}, None, time.monotonic()-t0))
    except Exception as exc:
        run.add_step(ForensicStepResult("network_flag", False, {}, str(exc), time.monotonic()-t0))

    run.completed_at = datetime.utcnow()

    if output_path:
        with open(output_path, "w") as f:
            f.write(run.to_report_json())

    return run

Concept 2 — Reporting: Forensic Findings to Stakeholders


A forensics report has two audiences: (1) the IR team / legal — full technical detail; (2) management — executive summary with business impact. Python can auto-generate both from the same data structure.


Example:


from dataclasses import dataclass
from datetime import datetime
from typing import Optional

@dataclass
class ForensicReport:
    case_id: str
    hostname: str
    analyst: str
    generated_at: datetime
    run: ForensicsRun
    executive_summary: str
    key_findings: list[str]
    recommendations: list[str]
    evidence_list: list[EvidencePackage]

    def render_executive_md(self) -> str:
        lines = [
            f"# Forensic Investigation Report — {self.case_id}",
            "",
            f"**Host:** {self.hostname}  ",
            f"**Analyst:** {self.analyst}  ",
            f"**Generated:** {self.generated_at.isoformat()}  ",
            "",
            "## Executive Summary",
            self.executive_summary,
            "",
            "## Key Findings",
        ]
        for i, f in enumerate(self.key_findings, 1):
            lines.append(f"{i}. {f}")
        lines.extend(["", "## Recommendations"])
        for i, r in enumerate(self.recommendations, 1):
            lines.append(f"{i}. {r}")
        lines.extend(["", "## Evidence Items"])
        for ev in self.evidence_list:
            lines.append(f"- {ev.evidence_id}: {ev.description} (SHA256: {ev.sha256[:16]}...)")
        return "\n".join(lines)

    def render_technical_md(self) -> str:
        sections = [self.render_executive_md(), "", "## Technical Detail", ""]
        if self.run.hollow_findings:
            sections.append("### Hollow Process Findings")
            for h in self.run.hollow_findings:
                sections.append(f"- PID {h.pid} ({h.process_name}): {h.verdict}")
        if self.run.suspicious_flows:
            sections.append("### Suspicious Network Flows")
            for flow, reasons in self.run.suspicious_flows:
                sections.append(f"- {flow.src_ip}:{flow.src_port} → {flow.dst_ip}:{flow.dst_port}: {'; '.join(reasons)}")
        return "\n".join(sections)
