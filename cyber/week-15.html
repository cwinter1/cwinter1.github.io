Concept 1 — Azure Log Taxonomy

Azure generates logs at three distinct layers, each with different retention defaults, query latency, and cost profiles. Understanding which layer a log lives in determines how you write detections and how quickly you can respond.

Activity Logs capture control-plane operations — who created a VM, who changed a firewall rule, who assigned a role. These are tenant-scoped and free up to 90 days. Think of them as your DDL audit log: they record schema changes (infrastructure changes), not row-level operations (user behavior).

Diagnostic Logs capture data-plane operations — sign-ins, resource access, application events. These must be explicitly routed to a Log Analytics Workspace. By default they go nowhere. This is the equivalent of SET AUDIT_TRAIL = DB in Oracle — it must be turned on.

Microsoft Sentinel is a SIEM layer on top of Log Analytics. It adds UEBA (User and Entity Behavior Analytics), incident management, and KQL-based analytics rules. A Sentinel analytics rule is functionally identical to a scheduled KQL query that fires an alert when row count > 0.

Data flows: Azure service → Diagnostic Settings → Log Analytics Workspace → Sentinel connectors → analytics rules → incidents.

Key tables in Sentinel:

Table What it contains
SigninLogs Azure AD interactive sign-ins
AADNonInteractiveUserSignInLogs OAuth token acquisitions, app sign-ins
AuditLogs Azure AD config changes (user creation, role assignment)
AzureActivity ARM control-plane (resource create/delete/modify)
SecurityEvent Windows Security events from connected VMs
OfficeActivity M365 (Exchange, SharePoint, Teams)

Analogy: Log Analytics Workspace = a managed data warehouse. Sentinel = a BI layer with scheduled reports that page oncall when a threshold is crossed. Diagnostic Settings = the ETL job that loads data into the warehouse. Without the ETL job, the warehouse is empty.

    R = 6371.0

// KQL — Microsoft Sentinel analytics rule
// Impossible Travel Detection
let MaxSpeedKmH = 900.0;
let LookbackHours = 24h;
SigninLogs
| where TimeGenerated >= ago(LookbackHours)
| where ResultType == "0"                          // successful sign-ins only
| project TimeGenerated, UserPrincipalName, IPAddress,
          Location, Latitude, Longitude, AppDisplayName,
          AuthenticationRequirement, RiskLevelDuringSignIn
| order by UserPrincipalName asc, TimeGenerated asc
| serialize                                         // required before prev()
| extend PrevTime      = prev(TimeGenerated, 1),
         PrevLocation  = prev(Location, 1),
         PrevLat       = prev(Latitude, 1),
         PrevLon       = prev(Longitude, 1),
         PrevUser      = prev(UserPrincipalName, 1)
| where UserPrincipalName == PrevUser               // same user, consecutive rows
| where Location != PrevLocation                    // different country
| extend ElapsedHours = datetime_diff('second', TimeGenerated, PrevTime) / 3600.0
| extend DistanceKm = 2 * 6371.0 * asin(sqrt(
    pow(sin(radians(Latitude - PrevLat) / 2), 2) +
    cos(radians(PrevLat)) * cos(radians(Latitude)) *
    pow(sin(radians(Longitude - PrevLon) / 2), 2)
  ))
| extend SpeedKmH = DistanceKm / ElapsedHours
| where SpeedKmH > MaxSpeedKmH
| project TimeGenerated, UserPrincipalName, IPAddress,
          Location, PrevLocation, DistanceKm, ElapsedHours, SpeedKmH,
          AuthenticationRequirement, RiskLevelDuringSignIn, AppDisplayName

import pandas as pd
import numpy as np

def haversine_vectorized(lat1: pd.Series, lon1: pd.Series,
                          lat2: pd.Series, lon2: pd.Series) -> pd.Series:
    R = 6371.0
    dlat = np.radians(lat2 - lat1)
    dlon = np.radians(lon2 - lon1)
    a = np.sin(dlat/2)**2 + np.cos(np.radians(lat1)) * np.cos(np.radians(lat2)) * np.sin(dlon/2)**2
    return 2 * R * np.arcsin(np.sqrt(a))

def detect_impossible_travel(df: pd.DataFrame, max_speed_kmh: float = 900.0) -> pd.DataFrame:
    df = df.sort_values(["UserPrincipalName", "TimeGenerated"]).copy()
    df["PrevTime"]     = df.groupby("UserPrincipalName")["TimeGenerated"].shift(1)
    df["PrevLocation"] = df.groupby("UserPrincipalName")["Location"].shift(1)
    df["PrevLat"]      = df.groupby("UserPrincipalName")["Latitude"].shift(1)
    df["PrevLon"]      = df.groupby("UserPrincipalName")["Longitude"].shift(1)

    df = df.dropna(subset=["PrevTime"])
    df = df[df["Location"] != df["PrevLocation"]]

    df["ElapsedHours"] = (df["TimeGenerated"] - df["PrevTime"]).dt.total_seconds() / 3600.0
    df = df[df["ElapsedHours"] > 0]

    df["DistanceKm"] = haversine_vectorized(df["PrevLat"], df["PrevLon"], df["Latitude"], df["Longitude"])
    df["SpeedKmH"] = df["DistanceKm"] / df["ElapsedHours"]

    return df[df["SpeedKmH"] > max_speed_kmh][
        ["TimeGenerated", "UserPrincipalName", "Location", "PrevLocation",
         "DistanceKm", "ElapsedHours", "SpeedKmH"]
    ].reset_index(drop=True)

A Sentinel analytics rule is a scheduled KQL query wrapped in metadata that controls alert frequency, severity, incident grouping, and entity mapping. Understanding the metadata fields is essential for writing production rules that don't flood the SOC with duplicate incidents.

A rule that runs every 5 minutes looking back 5 minutes is a real-time streaming detection. A rule that runs every 24 hours looking back 7 days is a batch anomaly hunt. Most production rules live somewhere between.

Concept 2 — GCP IAM Abuse Detection Patterns


IAM (Identity and Access Management) is GCP's permission layer. Every API call is authorized against an IAM policy. Attackers who gain initial access (via phishing, leaked service account keys, or OAuth token theft) immediately try to escalate privileges and establish persistence by creating new service accounts, generating keys, or granting themselves owner roles.


The four-stage GCP IAM attack pattern:


    

  1. Initial foothold — Attacker obtains a service account JSON key from a leaked repo, CI/CD misconfiguration, or compromised developer workstation
    2. 

  2. Reconnaissance — Calls projects.getIamPolicy, resourcemanager.projects.list, storage.buckets.list to understand the environment. These are Data Access logs — only visible if Data Access logging is enabled
    3. 

  3. Privilege escalation — Calls SetIamPolicy to grant themselves roles/owner or roles/iam.securityAdmin on the project
    4. 

  4. Persistence — Creates a new service account, generates a key, and uses that as a backdoor even after the original credential is rotated
    5.

def extract_granted_roles(request: dict) -> list[str]:
    roles = []
    bindings = request.get("policy", {}).get("bindings", [])
    for binding in bindings:
        roles.append(binding.get("role", ""))
    return roles

# Python-based YARA-L rule validator (structural check)
import re

def validate_yara_l_rule(rule_text: str) -> list[str]:
    errors = []

    if not re.search(r'rule\s+\w+\s*\{', rule_text):
        errors.append("Missing rule declaration")

    required_sections = ["meta:", "events:", "match:", "condition:"]
    for section in required_sections:
        if section not in rule_text:
            errors.append(f"Missing section: {section}")

    meta_fields = ["author", "description", "severity", "mitre_attack_technique"]
    for field in meta_fields:
        if field not in rule_text:
            errors.append(f"Missing meta field: {field}")

    valid_severities = {"LOW", "MEDIUM", "HIGH", "CRITICAL"}
    sev_match = re.search(r'severity\s*=\s*"(\w+)"', rule_text)
    if sev_match and sev_match.group(1) not in valid_severities:
        errors.append(f"Invalid severity: {sev_match.group(1)}")

    mitre_match = re.search(r'mitre_attack_technique\s*=\s*"(T\d{4}(?:\.\d{3})?)"', rule_text)
    if not mitre_match:
        errors.append("mitre_attack_technique must match T\\d{4} or T\\d{4}.\\d{3}")

    return errors

def ip_in_range(ip: str, cidr: str) -> bool:
    try:

    except ValueError:
        return False

class ImpossibleTravelFPFilter:
    min_speed_kmh: float = 900.0
    max_elapsed_hours_to_alert: float = 4.0
    min_elapsed_hours_to_alert: float = 0.1   # < 6 min is likely clock skew

    exclude_corporate_egress: bool = True
    exclude_service_accounts: bool = True

        upn = alert_row["UserPrincipalName"]
        ip = alert_row["IPAddress"]
        elapsed = alert_row["ElapsedHours"]
        speed = alert_row["SpeedKmH"]

        if speed < self.min_speed_kmh:
            return False, "below_speed_threshold"
        if elapsed > self.max_elapsed_hours_to_alert:
            return False, "elapsed_too_long"
        if elapsed < self.min_elapsed_hours_to_alert:

            return False, "known_vpn"
        if self.exclude_corporate_egress and is_corporate_egress(ip):
            return False, "corporate_egress"

        return True, "alert"

Concept 1 — Multi-Cloud Normalization Schema


When a SOC covers multiple cloud platforms, analysts face a terminology mismatch problem: Azure calls it UserPrincipalName, GCP calls it principalEmail, AWS calls it userIdentity.arn. A normalization layer maps all platforms to a shared schema — the same problem solved by Elastic Common Schema (ECS) and OCSF (Open Cybersecurity Schema Framework).


from dataclasses import dataclass
from datetime import datetime
from enum import Enum
from typing import Optional

class CloudEventType(Enum):
    IAM_CHANGE = "iam_change"
    LOGIN = "login"
    RESOURCE_CREATE = "resource_create"
    RESOURCE_DELETE = "resource_delete"
    DATA_ACCESS = "data_access"
    POLICY_CHANGE = "policy_change"
    CONFIG_CHANGE = "config_change"

class CloudPlatformEnum(Enum):
    AZURE = "azure"
    GCP = "gcp"
    AWS = "aws"

@dataclass
class NormalizedCloudEvent:
    # Shared schema across all platforms
    event_id: str
    timestamp: datetime
    platform: CloudPlatformEnum
    event_type: CloudEventType
    actor_identity: str         # UPN / email / ARN
    actor_ip: str
    actor_user_agent: str
    target_resource: str        # resource name / ARN / GCP resource
    target_project: str         # subscription / project / account
    action: str                 # method name / operation name
    outcome: str                # "success" or "failure"
    raw_payload: dict

    @classmethod
    def from_azure_signin(cls, log: dict) -> "NormalizedCloudEvent":
        return cls(
            event_id=log.get("CorrelationId", ""),
            timestamp=datetime.fromisoformat(log["TimeGenerated"].replace("Z", "")),
            platform=CloudPlatformEnum.AZURE,
            event_type=CloudEventType.LOGIN,
            actor_identity=log["UserPrincipalName"],
            actor_ip=log["IPAddress"],
            actor_user_agent=log.get("DeviceDetail", {}).get("browser", ""),
            target_resource="AzureAD",
            target_project=log.get("TenantId", ""),
            action="UserSignIn",
            outcome="success" if log.get("ResultType") == "0" else "failure",
            raw_payload=log,
        )

    @classmethod
    def from_gcp_audit(cls, entry: dict) -> "NormalizedCloudEvent":
        proto = entry.get("protoPayload", {})
        return cls(
            event_id=entry.get("insertId", ""),
            timestamp=datetime.fromisoformat(entry["timestamp"].replace("Z", "")),
            platform=CloudPlatformEnum.GCP,
            event_type=CloudEventType.IAM_CHANGE
            if "iam" in proto.get("serviceName", "") else CloudEventType.RESOURCE_CREATE,
            actor_identity=proto.get("authenticationInfo", {}).get("principalEmail", ""),
            actor_ip=proto.get("requestMetadata", {}).get("callerIp", ""),
            actor_user_agent=proto.get("requestMetadata", {}).get("callerSuppliedUserAgent", ""),
            target_resource=entry.get("resource", {}).get("type", ""),
            target_project=entry.get("resource", {}).get("labels", {}).get("project_id", ""),
            action=proto.get("methodName", ""),
            outcome="success" if proto.get("status", {}).get("code", 0) == 0 else "failure",
            raw_payload=entry,
        )

    def is_external_actor(self) -> bool:
        internal_domains = {"corp.com", "internal.corp.com", "svc.corp.com"}
        domain = self.actor_identity.split("@")[-1] if "@" in self.actor_identity else ""
        return domain not in internal_domains

import json

from pathlib import Path
from datetime import datetime
from dataclasses import dataclass, field, asdict
from typing import Optional

@dataclass
class CloudAlert:
    alert_id: str
    rule_id: str
    rule_title: str
    platform: str
    technique_id: str
    severity: str
    timestamp: str
    actor: str
    actor_ip: str
    target: str
    project: str
    action: str
    details: dict = field(default_factory=dict)
    suppressed: bool = False
    suppression_reason: str = ""

def run_impossible_travel_detection(events: list[NormalizedCloudEvent]) -> list[CloudAlert]:
    import math
    alerts = []
    login_events = [e for e in events if e.event_type == CloudEventType.LOGIN and e.outcome == "success"]
    by_actor: dict[str, list[NormalizedCloudEvent]] = {}
    for e in login_events:
        by_actor.setdefault(e.actor_identity, []).append(e)

    def _lat_lon_from_ip(ip: str) -> tuple[float, float]:
        # Stub: in production use MaxMind GeoIP2 or ip-api.com
        known = {
            "82.80.1.10": (32.08, 34.78),
            "185.220.101.5": (55.75, 37.62),
        }
        return known.get(ip, (0.0, 0.0))

    for actor, actor_events in by_actor.items():
        actor_events.sort(key=lambda e: e.timestamp)
        for i in range(1, len(actor_events)):
            prev, curr = actor_events[i - 1], actor_events[i]
            lat1, lon1 = _lat_lon_from_ip(prev.actor_ip)
            lat2, lon2 = _lat_lon_from_ip(curr.actor_ip)
            if (lat1, lon1) == (lat2, lon2) or (lat1, lon1) == (0.0, 0.0):
                continue
            elapsed_h = (curr.timestamp - prev.timestamp).total_seconds() / 3600.0
            if elapsed_h <= 0:
                continue
            dlat = math.radians(lat2 - lat1)
            dlon = math.radians(lon2 - lon1)
            a = math.sin(dlat/2)**2 + math.cos(math.radians(lat1)) * math.cos(math.radians(lat2)) * math.sin(dlon/2)**2
            dist_km = 2 * 6371 * math.asin(math.sqrt(a))
            speed = dist_km / elapsed_h
            if speed > 900 and elapsed_h < 4:
                alerts.append(CloudAlert(
                    alert_id=f"IT-{actor}-{int(curr.timestamp.timestamp())}",
                    rule_id="azure-impossible-travel",
                    rule_title="Azure AD Impossible Travel",
                    platform="azure",
                    technique_id="T1078",
                    severity="high",
                    timestamp=curr.timestamp.isoformat(),
                    actor=actor,
                    actor_ip=curr.actor_ip,
                    target="AzureAD",
                    project=curr.target_project,
                    action=curr.action,
                    details={"speed_kmh": round(speed, 0), "elapsed_hours": round(elapsed_h, 2),
                             "from_ip": prev.actor_ip, "to_ip": curr.actor_ip},
                ))
    return alerts

def run_gcp_iam_detection(events: list[NormalizedCloudEvent]) -> list[CloudAlert]:
    alerts = []
    PRIVILEGE_METHODS = {
        "google.cloud.resourcemanager.v3.Projects.SetIamPolicy",
        "google.iam.admin.v1.CreateServiceAccountKey",
    }
    for e in events:
        if e.platform != CloudPlatformEnum.GCP:
            continue
        if e.action not in PRIVILEGE_METHODS:
            continue
        if e.outcome != "success":
            continue
        ua = e.actor_user_agent.lower()
        if "terraform" in ua or "google-cloud-sdk" in ua:
            continue
        payload = e.raw_payload.get("protoPayload", {})
        bindings = payload.get("request", {}).get("policy", {}).get("bindings", [])
        priv_roles = [b["role"] for b in bindings
                      if b.get("role") in {"roles/owner", "roles/editor", "roles/iam.securityAdmin"}]
        if not priv_roles and e.action == "google.iam.admin.v1.CreateServiceAccountKey":
            priv_roles = ["service_account_key_created"]
        if priv_roles:
            alerts.append(CloudAlert(
                alert_id=f"GCP-IAM-{e.event_id}",
                rule_id="gcp-iam-escalation",
                rule_title="GCP IAM Privilege Escalation",
                platform="gcp",
                technique_id="T1078.004",
                severity="high",
                timestamp=e.timestamp.isoformat(),
                actor=e.actor_identity,
                actor_ip=e.actor_ip,
                target=e.target_resource,
                project=e.target_project,
                action=e.action,
                details={"privileged_roles": priv_roles},
            ))
    return alerts

def run_cloud_detection_pipeline(
    events: list[NormalizedCloudEvent],
    output_path: Optional[str] = None,
) -> list[CloudAlert]:
    all_alerts: list[CloudAlert] = []
    all_alerts.extend(run_impossible_travel_detection(events))
    all_alerts.extend(run_gcp_iam_detection(events))
    all_alerts.sort(key=lambda a: a.timestamp)

    summary = {
        "run_timestamp": datetime.utcnow().isoformat(),
        "events_processed": len(events),
        "alerts_fired": len(all_alerts),
        "by_rule": {},
        "by_severity": {},
    }
    for alert in all_alerts:
        summary["by_rule"][alert.rule_id] = summary["by_rule"].get(alert.rule_id, 0) + 1
        summary["by_severity"][alert.severity] = summary["by_severity"].get(alert.severity, 0) + 1

    output = {"summary": summary, "alerts": [asdict(a) for a in all_alerts]}
    if output_path:
        Path(output_path).write_text(json.dumps(output, indent=2), encoding="utf-8")
    return all_alerts

Concept 3 — Cloud Detection Sigma → KQL/Chronicle Conversion


The end-to-end production workflow converts Sigma rules to platform-specific query languages automatically, keeping the Sigma YAML as the single source of truth.


from pathlib import Path
import re

def sigma_to_kql_azure_signin(sigma_yaml: str) -> str:
    rule = yaml.safe_load(sigma_yaml)
    detection = rule.get("detection", {})
    condition = detection.get("condition", "")
    kql_filters: list[str] = []

    for block_name, block in detection.items():
        if block_name == "condition":
            continue
        if not isinstance(block, dict):
            continue
        block_is_filter = block_name.startswith("filter_")
        for field, value in block.items():
            kql_field = field.split("|")[0]
            operator = field.split("|")[1] if "|" in field else "eq"
            if isinstance(value, list):
                values_str = ", ".join(f'"{v}"' for v in value)
                if operator == "endswith":
                    parts = " or ".join(f'{kql_field} endswith "{v}"' for v in value)
                    clause = f"({parts})"
                elif operator == "contains":
                    parts = " or ".join(f'{kql_field} contains "{v}"' for v in value)
                    clause = f"({parts})"
                else:
                    clause = f"{kql_field} in ({values_str})"
            else:
                if operator == "eq":
                    clause = f'{kql_field} == "{value}"'
                else:
                    clause = f'{kql_field} {operator} "{value}"'

            if block_is_filter:
                kql_filters.append(f"| where not ({clause})")
            else:
                kql_filters.append(f"| where {clause}")

    logsource = rule.get("logsource", {})
    table = "SigninLogs" if logsource.get("service") == "signinlogs" else "AzureActivity"

    lines = [
        f"// {rule.get('title', 'Sigma Rule')}",
        f"// Technique: {', '.join(t for t in rule.get('tags', []) if 'attack.t' in t)}",
        f"// Level: {rule.get('level', 'unknown')}",
        table,
    ] + kql_filters + [
        "| project TimeGenerated, UserPrincipalName, IPAddress, Location, ResultType, ResultDescription"
    ]
    return "\n".join(lines)
